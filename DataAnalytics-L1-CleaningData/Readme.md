# Task 3: Data Cleaning and Quality Assessment

## Project Overview
This project focuses on cleaning a deliberately messy customer dataset using Python, Pandas, and NumPy. The aim is to identify data quality issues, handle missing and invalid values, standardize inconsistent data, and prepare a clean dataset for analysis.

## Objectives
- Generate an initial data quality report.
- Identify and handle missing values.
- Detect and remove duplicate records.
- Standardize inconsistent text and date formats.
- Detect and handle outliers using the IQR method.
- Correct data types and validate data ranges.
- Compare data quality before and after cleaning.
- Export the cleaned dataset to a new CSV file.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Description
The project uses a customer dataset containing information such as customer ID, name, gender, joining date, city, annual income, purchase amount, rating, and email.

The raw dataset contains data quality issues, including missing values, duplicate records, inconsistent formatting, invalid values, and outliers.

## Project Workflow
1. Loaded and inspected the raw dataset.
2. Generated an initial data quality report.
3. Identified and handled missing and invalid values.
4. Detected and removed duplicate records.
5. Standardized gender, city, email, and date formats.
6. Detected numerical outliers using the Interquartile Range (IQR) method.
7. Corrected column data types.
8. Compared data quality before and after cleaning.
9. Validated the cleaned dataset.
10. Exported the cleaned data to a CSV file.

## Data Cleaning Decisions
- **Missing numerical values:** Handled using median imputation where appropriate.
- **Missing categorical values:** Handled using the mode where appropriate.
- **Invalid values:** Converted to missing values before applying suitable cleaning strategies.
- **Duplicate records:** Identified and removed.
- **Inconsistent formatting:** Standardized text, email addresses, and dates.
- **Outliers:** Identified using the IQR method and treated according to the selected cleaning rules.
- **Data types:** Converted to suitable types for analysis.
- **Essential information:** Records missing required customer details or valid joining dates were removed according to the cleaning rules.

## Before-and-After Evaluation
The notebook compares the original and cleaned datasets based on:
- Number of rows
- Missing values
- Duplicate records
- Data types
- Data validation results

## Project Files
- `Data_Cleaning_Analysis.ipynb` — Jupyter Notebook containing the complete analysis and cleaning process.
- `data/messy_customer_data_cleaning.csv` — Original raw dataset.
- `data/cleaned_customer_data.csv` — Cleaned dataset generated by the notebook.
- `screenshots/` — Screenshots documenting the key stages and outputs.

## Final Outcome
The project demonstrates a structured data cleaning workflow and produces a cleaned, standardized dataset ready for further analysis.
