# Task 5: Autocomplete and Autocorrect Data Analytics

## Project Overview
This project analyses autocomplete and autocorrect techniques using Natural Language Processing (NLP). It explores word frequencies, predicts the next word, corrects spelling errors, and evaluates model performance.

## Dataset
- **Dataset:** Enron Email Dataset
- **File:** `emails.csv`
- **Source:** [Kaggle — Enron Email Dataset](https://www.kaggle.com/datasets/wcukierski/enron-email-dataset)

## Technologies Used
- Python
- Pandas and NumPy
- NLTK
- PySpellChecker
- Scikit-learn
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Workflow
1. Load and inspect the text dataset.
2. Clean and preprocess text.
3. Analyse the 20 most frequent words.
4. Build and test autocomplete models using n-grams.
5. Implement and evaluate autocorrect approaches.
6. Test autocomplete with at least 10 prefixes.
7. Test autocorrect with at least 20 misspelled words.
8. Calculate precision and recall.
9. Compare model performance using tables and visualizations.
10. Discuss limitations compared with Google Keyboard.

## Project Structure
- `data/` — Input dataset.
- `output/` — Generated graphs and CSV results.
- `screenshots/` — Evidence of completed analysis.

## Limitations
The models use a limited vocabulary and simplified prediction or correction methods. They may not understand context, sentence meaning, slang, or personal typing patterns as effectively as Google Keyboard.

## Conclusion
This project demonstrates text preprocessing, word-frequency analysis, autocomplete prediction, spelling correction, and model evaluation using Python and NLP.
