# Customer Segmentation Analysis

## Project Overview
This project uses Python and K-Means clustering to segment customers based on their purchasing behaviour. The goal is to identify different customer groups and suggest suitable marketing strategies.

## Objective
- Analyze online retail transaction data.
- Clean and prepare the dataset.
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Apply K-Means clustering to identify customer segments.
- Visualize clusters and recommend marketing strategies.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load and inspect the dataset.
2. Handle missing values, duplicates, and invalid transactions.
3. Perform exploratory data analysis (EDA).
4. Calculate RFM metrics for each customer.
5. Scale the RFM features.
6. Use the Elbow Method and Silhouette Score to evaluate cluster counts.
7. Apply K-Means clustering.
8. Visualize and profile customer segments.
9. Suggest marketing strategies based on customer behaviour.

- Identification of customer groups with different purchasing patterns.
- Comparison of customer recency, frequency, and monetary value.

This project demonstrates how exploratory data analysis, RFM analysis, and K-Means clustering can help an online retail business understand its customers and plan more targeted marketing campaigns.
